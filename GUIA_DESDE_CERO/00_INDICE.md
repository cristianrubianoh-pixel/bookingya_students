# Guía BookingYa desde cero (sin experiencia previa)

Si nunca has usado Git, Docker, Java o pruebas automatizadas, empieza aquí.

## Orden de estudio (obligatorio)

1. `01_PREPARAR_PC.md`
2. `02_CLONAR_Y_CONFIGURAR.md`
3. `03_LEVANTAR_BASE_CON_DOCKER.md`
4. `04_LEVANTAR_API_Y_PROBAR.md`
5. `05_DESARROLLO_TDD_BDD_ATDD.md`
6. `06_ENTREGA_FINAL.md`
7. `08_EVIDENCIAS_PARA_VIDEO.md` (opcional pero recomendado antes de grabar)
8. `09_COMANDOS_CONSOLA_POR_FASE.md` (comandos PowerShell por fase para mostrar resultado al profesor)

## Qué vas a lograr al final

- Tener el proyecto corriendo en tu computador.
- Entender qué pruebas debes crear en cada enfoque (TDD, BDD, ATDD).
- Saber qué mostrar como evidencia para la entrega.

## Regla de oro

No avances al siguiente archivo si el actual no te funciona.
